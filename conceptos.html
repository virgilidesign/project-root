Conceptos

1. Etiquetas de texto

Las etiquetas de texto permiten organizar y dar formato al contenido de una página web. Podemos utilizar títulos, párrafos, negritas y cursivas para destacar información. 

<h1>Bienvenidos a mi web</h1>
<p>Este es un párrafo.</p>
<b>Texto en negrita</b>
<i>Texto en cursiva</i>
<strong>Texto importante</strong>
<em>Texto con énfasis</em>

2. Listas

Las listas sirven para organizar información de forma ordenada o desordenada. Podemos utilizar listas numeradas con <ol> o listas con viñetas mediante <ul>. 

<ul>
    <li>Manzanas</li>
    <li>Naranjas</li>
    <li>Plátanos</li>
</ul>

3. Imágenes

Las imágenes permiten añadir contenido visual a una página web. Para insertarlas utilizamos la etiqueta <img>, indicando la ubicación de la imagen y una descripción alternativa. 

<img src="paisaje.jpg"
     alt="Fotografía de un paisaje"
     width="400">

4. Tablas

Las tablas permiten presentar información organizada en filas y columnas. Se utilizan las etiquetas <table>, <tr>, <th> y <td>. 

<table border="1">
    <tr>
        <th>Nombre y apellidos</th>
        <th>Edad</th>
    </tr>
    <tr>
        <td>David Virgili Morales</td>
        <td>36</td>
    </tr>
</table>

5. Enlaces

Los enlaces permiten conectar diferentes páginas web o dirigir al usuario a otras direcciones de Internet. Para crearlos utilizamos la etiqueta <a> y el atributo href. 

<a href="https://www.google.com">
    Visitar Google
</a>

6. Comentarios

En HTML, los comentarios sirven para añadir notas o explicaciones dentro del código. No aparecen en la página web cuando la visualizas en el navegador. 

<!-- Este es un comentario en HTML -->
