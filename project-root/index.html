Aspectos básicos de HTML HTML (HyperText Markup Language) es el lenguaje de marcado que se utiliza para crear y estructurar páginas web. Permite organizar los contenidos de una página, como textos, imágenes, enlaces, vídeos y tablas. Es la base de cualquier sitio web. Las etiquetas HTML son elementos que indican al navegador cómo debe mostrar el contenido. Normalmente están formadas por una etiqueta de apertura y otra de cierre. Por ejemplo, P se utiliza para crear párrafos, H1 para títulos principales e IMG para insertar imágenes. Las etiquetas de formato de texto permiten destacar palabras o frases importantes. HTML dispone de diferentes etiquetas para modificar la apariencia y el significado del texto: - < b>: permite mostrar un texto en negrita. - < i>: permite mostrar un texto en cursiva. - < strong>: indica que un texto tiene especial importancia y normalmente se muestra en negrita. - < em>: sirve para dar énfasis a una palabra o frase y normalmente se muestra en cursiva.
